## Getting Started

### Prerequisites
- Staff portal access with member management permissions
- Current membership plan information
- Payment processing setup (if collecting payment immediately)

### Accessing the Signup Form
1. Log into the Staff Portal
2. Navigate to **Members** section
3. Click **Add New Member** or **Sign Up Member** button
4. The Member Signup Wizard will open

## Step-by-Step Signup Process

### Step 1: Personal Information
Collect the following basic information from the new member:

**Required Fields:**
- **First Name** - Member's legal first name
- **Last Name** - Member's legal last name  
- **Email Address** - Primary contact email (must be unique)
- **Phone Number** - Primary contact number
- **Date of Birth** - For age verification and birthday promotions

**Optional Fields:**
- **Middle Name** - If provided by member
- **Preferred Name** - What they like to be called
- **Emergency Contact** - Name and phone number
- **Profile Photo** - Can be added now or later

**Tips:**
- Verify email address spelling - this is used for all communications
- Ask for mobile number for SMS notifications
- Emergency contact is highly recommended for safety

### Step 2: Address Information
**Required Fields:**
- **Street Address**
- **City**
- **State/Province**
- **ZIP/Postal Code**
- **Country**

**Features:**
- Address autocomplete helps speed up entry
- System validates postal codes
- Billing address can be different from home address

### Step 3: Membership Plan Selection
**Available Plans:**
- **Basic Membership** - Gym access only
- **Premium Membership** - Gym + classes
- **VIP Membership** - All access + personal training
- **Student/Senior Discounts** - Reduced rates with verification
- **Corporate Plans** - For business partnerships

**Important Notes:**
- Explain plan benefits clearly to the member
- Pricing may vary by location
- Some plans have commitment periods
- Upgrade/downgrade options available later

### Step 4: Payment Information
**Payment Methods:**
- **Credit/Debit Card** - Most common
- **Bank Transfer/ACH** - For recurring payments
- **Cash** - For initial payments only
- **Check** - With manager approval

**Billing Options:**
- **Monthly** - Most flexible
- **Quarterly** - Small discount
- **Annual** - Best value
- **One-time** - Day passes or short-term

**Setup Process:**
1. Select payment method
2. Enter payment details securely
3. Choose billing frequency
4. Set up automatic renewal (recommended)
5. Process initial payment if required

### Step 5: Waivers & Agreements
**Required Documents:**
- **Liability Waiver** - Legal protection
- **Membership Agreement** - Terms and conditions
- **Privacy Policy** - Data usage consent
- **Photo Release** - For marketing (optional)

**Process:**
1. Present documents to member
2. Allow time to read thoroughly
3. Answer any questions
4. Obtain electronic or physical signature
5. Provide copy to member

### Step 6: Additional Services (Optional)
- **Personal Training** - Schedule consultation
- **Nutrition Counseling** - Diet planning services
- **Locker Rental** - Monthly or annual
- **Guest Passes** - For family/friends
- **Merchandise** - Gym apparel, supplements

### Step 7: Account Activation
**Final Steps:**
1. Review all information with member
2. Generate member ID and access card/fob
3. Set up online account access
4. Schedule facility tour
5. Provide welcome packet
6. Send confirmation email

## Payment Setup

### Credit/Debit Cards
1. **Supported Cards:** Visa, MasterCard, American Express, Discover
2. **Security:** PCI-compliant processing
3. **Auto-renewal:** Charged on same date monthly
4. **Failed Payments:** 3-day grace period, then suspension

### Bank Transfer (ACH)
1. **Setup Time:** 1-2 business days verification
2. **Lower Fees:** Reduced processing costs
3. **Reliability:** Less likely to fail than cards
4. **Requirements:** Valid checking account, routing number

### Payment Schedules
- **Monthly:** Charged on signup date each month
- **Quarterly:** Every 3 months, 5% discount
- **Annual:** Once per year, 10% discount
- **Pro-rated:** First month adjusted for mid-month start

## Common Issues & Solutions

### ❌ Email Already Exists
**Problem:** Email address is already in the system
**Solutions:**
1. Check if member had previous account
2. Use different email address
3. Contact IT to merge/update records
4. Add numbers or periods to existing email

### ❌ Payment Declined
**Problem:** Credit card or bank transfer fails
**Solutions:**
1. Verify card information
2. Check if card is expired
3. Contact member's bank
4. Try different payment method
5. Process payment later if needed

### ❌ Missing Required Fields
**Problem:** Form won't submit due to incomplete information
**Solutions:**
1. Review red highlighted fields
2. Ask member for missing information
3. Use "N/A" for truly unavailable optional fields
4. Complete required fields before proceeding

### ❌ System Performance Issues
**Problem:** Slow loading or timeouts during signup
**Solutions:**
1. Check internet connection
2. Refresh the page and start over
3. Try different browser
4. Contact IT support
5. Complete signup on paper as backup

## Best Practices

### 💡 Customer Service Tips
1. **Be Patient** - Signup can be overwhelming for new members
2. **Explain Everything** - Don't assume they understand gym terms
3. **Stay Positive** - Make them excited about their fitness journey
4. **Be Thorough** - Better to spend extra time now than fix issues later
5. **Follow Up** - Check in after their first few visits

### 💡 Efficiency Tips
1. **Prepare Materials** - Have forms and information ready
2. **Use Autocomplete** - Let technology speed up data entry
3. **Group Similar Tasks** - Do all signups in batches when possible
4. **Keep Notes** - Document any special circumstances
5. **Update Immediately** - Don't leave partial signups incomplete

### 💡 Compliance Notes
1. **Privacy Laws** - Follow GDPR/CCPA requirements
2. **Age Verification** - Check ID for minors
3. **Medical Clearance** - Some members may need doctor approval
4. **Documentation** - Keep all signed documents
5. **Data Security** - Never write down payment information
