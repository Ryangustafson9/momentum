# PWA Icons

This directory contains the Progressive Web App icons for the Momentum Gym Management App.

## Required Icons

The following icons are required for proper PWA functionality:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Generating Icons

You can generate these icons from a single high-resolution source image (1024x1024 recommended) using:

1. **Online Tools:**
   - PWA Builder (https://www.pwabuilder.com/)
   - Favicon Generator (https://realfavicongenerator.net/)

2. **Command Line Tools:**
   - ImageMagick
   - Sharp (Node.js)

3. **Design Tools:**
   - Figma
   - Adobe Illustrator
   - Canva

## Icon Requirements

- **Format:** PNG
- **Background:** Solid color or transparent
- **Content:** Should be recognizable at small sizes
- **Maskable:** Consider creating maskable versions for Android

## Temporary Placeholder

For development purposes, you can use a simple colored square as a placeholder until proper icons are created.
